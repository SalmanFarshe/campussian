Campussian is a 100% standalone school and education WordPress theme with a rich homepage, notice board, events, admission, gallery and Customizer options.

== Description ==

Campussian is a modern, standalone theme built for schools, colleges and educational institutions. It ships with:

* A modular, reorderable homepage (Customizer controlled section order and on/off toggles)
* Notice, Event, News, Gallery, Facility, Teacher and Alumni presentation templates
* Admission, Contact, Login and Dashboard page templates
* Native light and dark mode with a user-facing toggle
* A full Customizer panel under "Campussian Options"
* Self-hosted webfonts and bundled libraries - the theme makes no external requests

= Demo content =

The theme renders gracefully with no configuration. Demo posts for Notices, Events and the other custom post types are optional.

== Installation ==

1. In your admin panel, go to **Appearance > Themes** and click **Add New**.
2. Search for **Campussian** and click **Install**, or click **Upload Theme** and select the zip file.
3. Click **Activate** to start using the theme.

== Frequently Asked Questions ==

= Does this theme require a plugin? =

No. Campussian works standalone for all presentation. An optional companion plugin, **Campussian Core**, adds school role management (Student, Teacher, Guardian, Principal and Admin) plus a front-end portal. It is offered as a *recommended* plugin from **Appearance > Install Plugins** and is never required for the theme to function.

= How do I reorder the homepage sections? =

Go to **Appearance > Customize > Campussian Options > Homepage Sections**. Every section has an on/off toggle and the "Homepage Section Order" field controls the order (comma-separated slugs).

= How do I change the logo and colors? =

**Appearance > Customize > School Branding** for the logo and contact details. Colors use native Customizer live refresh.

== Privacy ==

The Campussian theme does not collect, store, transmit or track any personal data, and it does not set cookies or load third-party analytics, fonts or scripts. No remote requests are made from the theme; all styles, scripts and webfonts are bundled inside the theme package.

Data a site owner enters through the Customizer (such as contact details) is stored in that site's own database as normal WordPress content.

The optional Campussian Core plugin is responsible for its own data handling and ships its own documentation. Theme visitors can read the site's Privacy Policy page for details specific to that site.
